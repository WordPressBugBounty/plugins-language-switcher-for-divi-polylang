== Description ==

**Language Switcher for Polylang** is a powerful Polylang language switcher addon that lets you add a fully customizable **WordPress language switcher** anywhere on your WordPress website.

https://youtu.be/oRp8vmrU8yM

Whether you build your website with **Elementor**, **Gutenberg**, or **Divi**, this plugin provides dedicated integration to add an **Elementor language switcher**, **Gutenberg language switcher**, or **Divi language switcher** quickly without any complex coding. 
Simply insert the dedicated **Elementor widget**, **Gutenberg block**, or **Divi module**, customize its appearance, and that’s it.
Additionally, this plugin also includes a **Floating Language Switcher**, allowing users to change languages from anywhere on your website without requiring a switcher in the header, menu, or page content.
## Why use this Plugin?
**Language Switcher for Polylang** is a simple and easy way to add a language switcher to your Elementor, Gutenberg or Divi pages. Here’s why you should use this plugin:
* Dedicated Language Switcher Widget
* Dedicated Language Switcher Block
* Dedicated Language Switcher Module
* No Separate Menus for Each Language
* Floating Language Switcher
* Elementor Template Language Sync
* Add Anywhere on the Page
* Advance Customization Options
##Elementor Language Switcher for Polylang
* **Elementor Language Switcher:** Add a language switcher to your Elementor layouts using the dedicated **Language Switcher widget**. Simply drag and drop the widget into your page or header template.
* **Elementor Template Translation Sync:** The Elementor Template Translation Sync feature allows you to connect your **existing translated templates** with their corresponding language versions. 
Once the templates are linked, Polylang recognizes them as **translation pairs** and displays language options for each template. It also ensures that visitors see the correct translated Elementor template based on the language they have selected, without requiring separate display conditions.
* **Layout Options:** The plugin offers three layout styles, **Dropdown**, **Horizontal** & **Vertical**. Choose how you want the language switcher to appear on your website.
* **Customize Display:** Customize the appearance of the Elementor Language Switcher by adjusting **background color**, **text color**, **border color**, **width**, and more.
* **Custom Switcher Elements:** Enable or disable various elements such as:
 * **Language Flag:** Show a country flag icon next to each language **(🇺🇸)**.
 * **Language Name:** Show the full name like **“English”**, **“Spanish”**.
 * **Language Code:** Show short codes like **EN**, **FR**, **DE**.
 * **Hide Current Language:** Hides the active language.
 * **Hide Untranslated Languages:** Hide languages if the page has no translation in that language.
##Gutenberg Language Switcher Block
* **Gutenberg Language Switcher:** If you're using the WordPress Block Editor, you can insert the **Language Switcher block** anywhere on your website. Add it to pages, posts, templates, or block-based headers.
* **Layout Options:** Display the language switcher in a **Dropdown**, **Horizontal**, or **Vertical layouts** to match your website's design.
* **Customize Switcher Elements:** Control which language information is displayed by enabling or disabling the following:
 * **Language Flag:** Display a flag icon next to each language.
 * **Language Name:** Show the full language name, such as English or Spanish.
 * **Language Code:** Display language codes like **EN**, **FR**, or **DE**.
 * **Hide Current Language:** Hide the currently selected language from the switcher.
 * **Hide Untranslated Languages:** Hide languages that do not have a translated version of the current page.
* **Customize Display:** Customize the appearance of the Gutenberg Language Switcher by adjusting **background color**, **text color**, **border color**, **width**, and more.
##Divi Language Switcher Module
* **Divi Language Switcher:** The plugin also includes a dedicated **Language Switcher module for Divi**. Add it to your website header using the Divi Theme Builder or place it anywhere within your layouts. 
* **Layout Options:** The plugin offers three layout styles, **Dropdown**, **Horizontal** & **Vertical**. Choose how you want the language switcher to appear on your website.
* **Customize Switcher Elements:** Easily customize the appearance of the language switcher elements by enabling or disabling the following:
 * **Language Flag:** Show a small flag icon next to each language **(e.g., 🇺🇸)**.
 * **Language Name:** Display the full language name **(e.g., English, Spanish)**.
 * **Language Code:** Show language short codes like **EN**, **FR**, **DE**, etc.
 * **Hide Current Language:** Hide the language that is currently active.
 * **Hide Untranslated Languages:** Hide specific languages if the current page has no translated version available in that language.
* **Customize Display:** Customize the appearance of the Divi Language Switcher by adjusting **background color**, **text color**, **border color**, **width**, and more.
##Floating Language Switcher for Polylang
* **Floating Language Switcher:** Enable a floating language switcher for Polylang that remains visible as visitors browse your website. This frontend language switcher for Polylang allows users to change languages from any page without placing a switcher in your header or navigation menu.  
* **Ready-to-Use Presets:** Choose from multiple pre-made **light**, **dark**, **bordered**, and **transparent presets** according to your website's style.
* **Layout Options:** The plugin offers two layout styles, **Dropdown**, **side by side**. Choose how you want the language switcher to appear on your website.
* **Customize Layout:** Customize the layout of the floating language switcher using following settings:
 * **Flag Icon Position:** Choose whether you want a flag icon before language, after language, or want to hide icons.
 * **Language Names:** Choose whether you want to display full language names, short names, or none.
* **Customize Display:** Customize the appearance of the floating switcher by adjusting **background color**, **text color**, **text hover color**, **border color**, **width**, **radius**, and more.
##Other Features
* **Works with Popular Page Builders:** Add a language switcher anywhere on your website using the tools you already use. The plugin includes dedicated integrations for **Elementor**, **Gutenberg**, and **Divi**, allowing you to insert a language switcher using a widget, block, or module.
* **Built for Polylang:** This plugin is built exclusively for **Polylang** and works seamlessly with your existing language configuration. Simply install the plugin, and it will automatically recognize the languages you've added in Polylang and display them in the **Polylang language switcher**. 
* **Easy to Use:** Get your multilingual language switcher up and running in just a few minutes. Install the plugin, choose your preferred switcher **type**, **customize** its appearance, and publish it anywhere on your website without any coding knowledge.
* **Fully Responsive:** The language switcher is designed to work seamlessly across all screen sizes. Whether your visitors browse from a desktop, tablet, or mobile device, the switcher automatically adapts to provide a consistent and user-friendly language selection experience.

== Installation ==
* **Install Plugin**
 * First, make sure that you have installed and activated the Polylang plugin and Language Switcher for Polylang – Elementor, Gutenberg & Divi on your WordPress website.
* **Add Elementor Language Switcher**
 * Edit the header template with Elementor or create a new one.
 * Drag and drop the **Language Switcher widget** into your header.
 * Next, **customize** and **configure** the Language Switcher display according to your requirements.
 * Save your changes and preview the language switcher on the frontend.
* **Translate Elementor Templates**
 * From your WordPress Dashboard, Navigate to
**Templates > Saved Templates**.
 * Create a new Elementor template or edit an existing one.
 * Use **Polylang language options** to add translations for the template.
 * Translate the content and save the template.
 * Each translated template will be linked automatically, ensuring the correct language version is displayed on your website.
* **Add Gutenberg Language Switcher**
 * Insert the **Language Switcher block** into any page or post.
 * Choose how languages are displayed (flags, names, or both).
 * Customize **alignment**, **styling**, and **switcher behavior**.
 * Publish the page to make the language switcher available on your site.
* **Add Divi Language Switcher**
 * Navigate to **Divi Theme Builder**, add a new or edit an existing header template.
 * Add the **Language Switcher module** where you want it to appear.
 * Next, **customize** and **configure** your language switcher display using Divi's design settings.
 * Save your changes and preview the header on the frontend.
* **Floating Language Switcher**
 * From your WordPress Dashboard, navigate to **Languages > Language Switcher > Floating Language Switcher**.
 * Enable the **Floating Language Switcher**. Once enabled, the switcher will appear on the front end of your website.
 * Next, choose the **switcher type** and customize its design according to your requirements.
 * Click **Save Changes**, your floating language switcher will be live. 
== Frequently Asked Questions ==
= Does this plugin require Polylang? =
Yes. Language Switcher for Polylang is an addon for the Polylang plugin. You must install and activate Polylang before using this plugin.
= Can I add a language switcher using Elementor? =
Yes. The plugin includes a dedicated Elementor Language Switcher widget that you can drag and drop anywhere in your Elementor pages, templates, or headers.
= Will this plugin work with Elementor Free or Elementor Pro? =
Yes, it works with both. The plugin uses the Elementor widget system, which is available in the free version.
= Does it support the WordPress Block Editor (Gutenberg)? =
Yes. You can add a Gutenberg Language Switcher block to any page, post, template, or block-based header without using shortcodes or custom code.
= Can I use the language switcher with Divi? =
Absolutely. The plugin provides a dedicated Divi Language Switcher module that can be added anywhere in your Divi layouts or Theme Builder templates.
= Do I need to create separate menus for each language? =
No, unlike the default Polylang setup, you don’t need to manually create or assign separate menus for each language. The plugin allows for an easier, automatic solution.
= Can I display a floating language switcher? =
Yes. Simply enable and customize the Floating Language Switcher from the plugin dashboard settings. It will remain visible while visitors browse your website, allowing them to switch languages from any page.
= Can I display language names, flags, or both? =
Yes. Using the language switcher for the Polylang plugin you can choose to display language names, country flags, or a combination of both to create a language selector that matches your website's design.
= Can I customize the appearance of the language switcher? =
Yes. You can customize colors, typography, spacing, borders, alignment, layouts, and other styling options of your language switcher to match your website.
= Will the plugin automatically detect my Polylang languages? =
Yes. Once your languages are configured in Polylang, the plugin automatically detects them and displays them in the language switcher.
= Can I add the Polylang language switcher to my website header? =
Yes. You can easily add the language switcher to your website header using the Elementor widget, Gutenberg block, or Divi module, depending on the page builder you use.
= Can I preview changes before publishing? =
Yes, you can preview the language switcher on your page before making any changes live. The plugin offers a frontend display preview to ensure everything appears correctly before you publish.
= Is this plugin compatible with Polylang Pro? =
Yes, the plugin is fully compatible with both the free and Pro versions of Polylang.
= Can I add the switcher in a header or footer? =
Absolutely! You can add the language switcher widget in any section, including headers, footers, sidebars, or even popups.
= How do I link existing Elementor templates with Polylang? =
If your Elementor templates were translated before installing Polylang plugin, simply open the template in the Elementor Editor, assign its language using Polylang, and save it. The Polylang Language switcher plugin automatically links the translated templates and restores the language relationships.
= Does the plugin work with existing translated Elementor templates? =
Yes. You don't need to recreate your templates. The plugin can connect your existing translated Elementor templates with Polylang so they behave like native multilingual templates.

= Where do I report security bugs found in this plugin? =
Please report security bugs found in the source code of the Language Switcher for Polylang plugin through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/0da29e56-bc01-46c8-a6f4-363ea6c69652). The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.
